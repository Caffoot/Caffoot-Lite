# Required references for Caffoot Lite Next

This directory temporarily retains the minimum audited v1.3.x implementation evidence needed to build Next without changing published v1.3.3 behaviour. **GitHub issue #215 is the only approved Next build specification.** These files are reference evidence, not competing requirements. Historical observations must be reconciled against later fixes and the published v1.3.3 source and tests before acting.

## Contents

- `workflows--*`: existing application behaviour and device/software compatibility.
- `standards--*`: established function naming, code, design, development and documentation conventions.
- `testing--*`: regression scenarios, import compatibility and verification coverage.
- `audits--*`: historical findings, reconciliation and execution evidence; not proof of current defects.

Do not interpret obsolete browser-storage infrastructure or historical release processes as Next requirements. Do not implement new features from these references. Before Next becomes `main`, replace this temporary collection with accurate permanent technical documentation and remove unnecessary development-only records.
