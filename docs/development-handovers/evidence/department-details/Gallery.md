# Department Details screenshot gallery

Actual unreleased v2.2 application, using fictional test records. These captures
support review; they do not constitute final product-owner acceptance. See the
[implementation report and source/check details](Report.md).

Select any image to open its full-size PNG. Mobile tab strips and wide tables
scroll horizontally in the application; the screenshots retain their actual framing.
