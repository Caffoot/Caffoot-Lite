# IP address management and subnets

**Published release:** v1.3.0. **Status:** Website reference draft; verify against published UI before publication.

## What it does

Document network address blocks, subnets, VLAN-related information and individual IP address assignments and reservations.

## What users can do

- Create and manage subnet records and inspect address availability.
- Record IP allocations and reservations, including device relationships.
- Review bulk reservation or release changes before applying them.
- Use inventory validation to help identify inconsistent saved records.

## Important limitations

Caffoot Lite is an inventory tool, not an authoritative DHCP server, live network scanner or automatic address allocator for real network equipment. Bulk operations must be reviewed before application. A **Back to Editing** action from the bulk confirmation view is proposed, not currently advertised as available.

## Suggested website description

**Make sense of your IP address space.** Document subnets, track address assignments and reservations, and review changes before saving them.
