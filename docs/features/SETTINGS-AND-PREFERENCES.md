# Settings and preferences

**Published release:** v1.3.0. **Status:** Website reference draft; verify against published UI before publication.

## What it does

Provide access to data management, appearance settings, help and application information.

## What users can do

- Select Light Mode, Dark Mode or Use System Setting for appearance.
- Access backup, restore, safety checking, update guidance and recovery controls.
- Read built-in help topics and application information.
- View a limited local Change History and download it separately.

## Important limitations

Appearance preferences are saved in the current browser when browser storage permits. A manual update check requires internet access; it does not automatically install a new version or transmit the inventory. Change History records summaries of certain saved changes, not a complete record of every field value. It is browser-local, limited to recent events and is not tamper-proof or included in standard inventory backups.

## Suggested website description

**Make Caffoot Lite your own.** Choose an appearance that suits your setup, access built-in help and manage backups from the settings area.
