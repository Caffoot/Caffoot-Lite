# Network racks

**Published release:** v1.3.0. **Status:** Website reference draft; verify against published UI before publication.

## What it does

Document physical network racks and the equipment installed within them.

## What users can do

- Create and manage rack records.
- Position rack-mounted devices and supported rack accessories in available U positions.
- Inspect front and rear rack arrangements where supported.
- Use placement checks to help avoid equipment overlapping in occupied rack positions.

## Important limitations

Rack diagrams describe the saved inventory; they do not automatically detect physical equipment. Users must enter accurate rack dimensions and placements. Do not promise unrestricted custom rack types or dimensions unless verified in the published release.

## Suggested website description

**See how your racks are arranged.** Document network cabinets, place devices and accessories, and use rack position checks to keep layouts organised.

## Screenshot guidance
