# Caffoot Lite — Public Roadmap

**Infrastructure, Simplified.** Caffoot Lite is free, open-source IP address management, device inventory and network rack documentation for small businesses, IT teams and home labs.

This page helps visitors see what is available, what is being developed and which ideas are being considered. **An idea is not a promised feature or release date.** The product owner decides priorities and approves changes before development.

## Available now — v2.1

Caffoot Lite v2.1 was published on **8 November 2026**. The current release includes:

- Device and IT asset inventory with improved physical-server and virtual-machine forms.
- Subnet-first IP address management (IPAM), optional VLANs and guided bulk subnet planning.
- Network rack documentation, front/rear views and equipment placement.
- Multi-user access, administrator-managed permissions, MFA, account/email workflows and Audit Trail.
- A modern, responsive light/dark interface and Docker/SQLite deployment with persistent data.

## In development — v2.2 (Milestone 01)

**v2.2 is the agreed target version, not a published release and not a release-date commitment.** Stage 1 (role-based access, per-user overrides, MFA safeguards and IT Staff) is accepted and merged; Stages 2–6 are not yet complete. Development continues on `milestone-1`, with scope, reviews and acceptance recorded in the [Milestone 01 tracker #351](https://github.com/Caffoot/Caffoot-Lite/issues/351). Only v2.1 installation instructions and published images are presently available. Documentation preparation is tracked in [#366](https://github.com/Caffoot/Caffoot-Lite/issues/366).

The [six long-term planning milestones](docs/product-direction/PROPOSED-MILESTONES.md) organise future proposals. **Milestone 01 — Everyday IT Management** includes upcoming Suppliers, a core Assets and stock section, People and Departments, equipment assignments and handovers, optional modules and the full Service Desk. **Milestone 02 — Connected Infrastructure** remains focused on network relationships. **Milestone 03 — Inventory Tools, Reporting & Verification** groups later inventory improvements such as CSV/JSON, saved views, QR labels, stocktakes, reporting and IT documentation. See the [live GitHub milestones](https://github.com/Caffoot/Caffoot-Lite/milestones). These are planning groupings: detailed feature scope and implementation still require separate approval; no release date is set. The completed v2.1 integration and its historical decisions are recorded in [issue #282](https://github.com/Caffoot/Caffoot-Lite/issues/282).

## Help shape Caffoot Lite

You don't need to write code to contribute. Try the current release, share your experience, tell us what was difficult or suggest something useful.

- **[Suggest a feature or report a bug](https://github.com/Caffoot/Caffoot-Lite/issues/new/choose)** — use one issue per suggestion, so decisions remain easy to follow.
- **[Find ways to contribute](docs/Community-Participation.md)** — testing, documentation and practical feedback are welcome.
- **[Read the contribution guide](CONTRIBUTING.md)** — our shared standards for welcoming and constructive participation.

Please [report security vulnerabilities privately](SECURITY.md), not in public issues.
