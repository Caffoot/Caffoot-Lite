Boot Storage

The selected ZFS pool and its VDEVs are recorded once. Boot Storage links to them without adding another set of drives.

A ZFS pool may contain multiple VDEVs. RAIDZ types belong to individual VDEVs rather than the server's existing conventional RAID dropdown.
