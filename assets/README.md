# Caffoot brand assets

Place the approved orange hedgehog artwork in this folder:

- `caffoot-icon-1024.png` — high-resolution app icon
- `caffoot-github-512.png` — GitHub branding image
- `apple-touch-icon.png` — Apple home-screen icon
- `favicon.ico` — browser favicon

These are source branding assets. The release build must embed any images it uses so the downloadable Caffoot Lite HTML remains fully offline and self-contained.

The Caffoot name and mascot are project branding; see the repository README for the distinction from the MIT software licence.
