Important: your inventory is stored in this browser

Your inventory is NOT saved inside Caffoot-Lite.html. It is stored only in this browser, without automatic cloud backup. Clearing browser data can erase it; changing browser, profile or HTML file location may make it inaccessible.

Keep regular JSON backups outside the browser. Always back up before upgrading, moving, renaming, restoring or resetting Caffoot Lite.

    Safely Update Caffoot Lite

    1. Download a JSON backup from the current version and keep it outside your browser.
    2. Keep your current HTML file. Download the new Caffoot-Lite.html from the official release page into a separate folder.
    3. Open the new file in your usual browser. Moving a file can change which saved inventory the browser can access. Some browsers share storage across local HTML files, so restoring in the new copy may also change inventory visible in the old copy.
    4. Use Settings & Data → Choose backup file if your inventory is missing or out of date. Review the import summary carefully: restoring replaces the inventory visible in that file.
    5. Check your devices, IPAM, subnets and racks before continuing. Keep the old HTML and backup until you are satisfied.

    Updates are manual. The application works offline; only checking for releases and downloading a newer file need internet access. A backup from a newer schema may require a newer application.
